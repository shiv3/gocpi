# Contributing

## Development

- `make generate` — regenerate `v221` types/clients/server handlers from the vendored OpenAPI spec
- `make test` / `make test-race` — run tests
- `make lint` — run golangci-lint
- `make tidy` — tidy go.mod

## Generated code

Files with `// Code generated by gocpi codegen. DO NOT EDIT.` are produced by
`internal/codegen` from the official OCPI OpenAPI specification (vendored under
`schemas/`). Never edit them by hand. Change the generator/templates or re-vendor
the spec and re-run `make generate`. CI fails if generated output drifts from
committed.

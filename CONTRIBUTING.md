# Contributing

## Development

- `make generate` — regenerate the `v221` (OCPI 2.2.1) and `v230` (OCPI 2.3.0)
  packages from the vendored OpenAPI specs
- `make test` / `make test-race` — run tests
- `make lint` — run golangci-lint
- `make tidy` — tidy go.mod

## Generated code

Files with `// Code generated by gocpi codegen. DO NOT EDIT.` (and the
`v2xx/schema.json` documents) are produced by `internal/codegen` from the
official OCPI OpenAPI specification vendored under `schemas/`. Never edit them by
hand. Change the generator/templates or re-vendor the spec and re-run
`make generate`. CI fails if generated output drifts from committed.

The generator is config-driven: it reads each version's `schemas/<version>/config.json`
to discover modules, interfaces and roles, so adding a new OCPI version is
largely a matter of vendoring its spec and running codegen.
